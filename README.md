# nvim-config

A lightweight and minimal Neovim configuration focused on a clean workflow, fast navigation, and a modern-looking UI.

## Features

- Catppuccin theme
- Custom status line with lualine
- File explorer with nvim-tree
- Fuzzy finding and searching with Telescope
- Syntax highlighting and indentation with Treesitter
- Simple keymaps for common actions

## Prerequisites

- Neovim 0.7 or newer
- Git

## If cloning:

1. go to ~/.config and rename nvim-config to nvim
2. type nvim and run :PackerSync once to install and update all plugins
